PROGRAM BEHAVIOUR

The program will display a welcome message and show a menu.

The menu will keep appearing until the user chooses Quit.

The program will use if, elif and else statements to run the selected tool.

Invalid choices will display a polite error message.

After each tool finishes, the menu will appear again.

A goodbye message will appear when the user quits.
